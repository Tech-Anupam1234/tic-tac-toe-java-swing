# 🎮 Tic Tac Toe Java Swing

A GUI-based Tic Tac Toe game built using Java Swing and AWT.

## Features

- Interactive 3x3 Game Board
- X and O Turn Management
- Winner Detection
- Draw Detection
- Scoreboard
- Restart Button
- Winning Move Highlight

## Technologies Used

- Java
- Swing
- AWT
